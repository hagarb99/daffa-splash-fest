# Project Rules & Technology Architecture (Strict Instructions)

This is a production-ready, full-stack web application built on **TanStack Start v1** with **React 19**, **Vite 7**, and **Tailwind CSS v4**.
You MUST strictly follow these rules to avoid breaking the application:

---

### 1. Framework & Routing (Do NOT use Next.js or React Router)
- **Framework**: TanStack Start v1 (NOT Next.js, NOT Remix, NOT CRA).
- **Routing**: `@tanstack/react-router` file-based routing.
- **NEVER install or import**:
  - `react-router-dom`
  - `next/link`, `next/navigation`, `next/image`
- **Route files**: All routes live in `src/routes/` (e.g. `src/routes/index.tsx`, `src/routes/activities.$slug.tsx`).
- **Route Tree**: `src/routeTree.gen.ts` is auto-generated by the TanStack router plugin. **NEVER manually edit `src/routeTree.gen.ts`**.
- **Root Layout**: Shared layout lives in `src/routes/__root.tsx` wrapping `<Outlet />`.
- Use `<Link to="...">` and `useNavigate()` from `@tanstack/react-router`.

---

### 2. Styling: Tailwind CSS v4 (No tailwind.config.js)
- **Engine**: Tailwind CSS v4 via `@tailwindcss/vite`.
- **CRITICAL**: Do **NOT** create `tailwind.config.js` or `postcss.config.js`. It will conflict with the Vite build and crash.
- Styling tokens and `@theme` variables are defined directly inside `src/styles.css`.
- Remote web fonts must be loaded via `<link>` tags in `src/routes/__root.tsx` head, NOT via `@import url(...)` in `src/styles.css`.
- UI Components are Radix UI + shadcn primitives located in `src/components/ui/`.
- Notifications: Use `sonner` (`import { toast } from "sonner"`). Do NOT create or import legacy `@/hooks/use-toast`.

---

### 3. Server Functions & Runtime
- Internal server actions use `createServerFn` from `@tanstack/react-start`.
- Method chaining syntax in installed version v1.167.50: `createServerFn().validator(zodSchema).handler(...)`.
  *(Note: In `@tanstack/react-start` v1.167.50, use `.validator(...)` as `.inputValidator` was removed in this release).*
- Runtime targets Edge/Cloudflare Workers (workerd) via Nitro.
- **Do NOT** use Node.js-only built-in modules (`fs`, `path`, `child_process`) in server functions.
- Environment variables:
  - Client side: `import.meta.env.VITE_*`
  - Server side: `process.env.*` (only accessible inside server handlers).

---

### 4. Backend & Supabase
- Client instance: `import { supabase } from "@/integrations/supabase/client"`.
- Do **NOT** manually alter auto-generated files:
  - `src/integrations/supabase/client.ts`
  - `src/integrations/supabase/types.ts`
  - `src/integrations/supabase/previewAuthStorage.ts`
  - `src/integrations/supabase/auth-attacher.ts`

---

### 5. Vite Configuration (`vite.config.ts`)
- Config uses `@lovable.dev/vite-tanstack-config` which already bundles TanStack Start, React 19, Tailwind v4, tsConfigPaths, and Nitro.
- Do **NOT** manually add duplicate Vite plugins for React, Tailwind, or TanStack in `vite.config.ts`.

---

### 6. Development & Scripts
- Install dependencies: `bun install` or `npm install --legacy-peer-deps`
- Start dev server: `npm run dev` or `bun dev` (runs on `localhost:8080`).
